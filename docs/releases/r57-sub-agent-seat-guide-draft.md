# r57 子 Agent 使用说明（上线草稿）

本说明对应第一期候选，尚未部署。启用时间和席位范围以正式发布通知为准。

一期支持同一自托管 Codex 主会话下的一级子会话。主、子各有独立任务队列和上下文，共用一个受控 app-server。子不是新账号，沿用主会话的权限与编组。Claude、外部席和二三级子节点尚未开放。

启用后，在主会话使用原生受控 sub_agent_control 工具的 create 操作；给此次请求一个稳定request_id，重试沿用原值。工具返回完整名和注册状态，只有树快照获Hub确认后才能接信。默认名来自新thread UUID随机末8位，冲突时延长；可在创建时提供别名。已结束的名字保留，不能拿来绑定新任务。

既有主thread没有安装dynamicTools时不会出现创建工具。尝试创建会明确提示「需重开主会话」，不会暗中创建节点或覆盖主绑定。请使用受支持的新主会话启动流程重开，再创建；平台不会自动替你切换旧主thread。

向子会话发信使用受控 dingwei_send_message 工具和完整目标，如 aa.agent.owner。不要把正文里的@子名当投递；提及候选仍只有根Agent。子会话经原生工具发信时来源由真实thread绑定，不能靠参数、环境变量或共享IPC自报。原信来源结束后，回信不会转给其父。

Console可看到「根 → 子」树及在线、离线、ended、原因。子页只读，历史、游标和费用独立；每个打开的根或子页各占一个订阅预算，总共最多8个。ended不等于暂时离线，离线也不代表已结束。旧Hub或旧helper不支持时会明确拒收子目标，根会话继续可用。

默认生命周期：显式任务完成即退出；空闲1小时；自创建最长2天；平台硬上限5天，按每个节点自己的创建时刻计算；退出宽限10分钟；父会话关闭时级联关闭。一次模型turn完成不会自动当作整个任务完成，需调用task_completed明确报告。

退出先封口。确定未执行的排队信逐封退回；可能已执行的信显示状态不确定，平台不会伪造完成或自动重投。需要主动结束时使用close；不要通过杀共享app-server来关闭单个孩子。
