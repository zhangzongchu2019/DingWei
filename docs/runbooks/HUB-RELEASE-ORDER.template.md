# Hub 发布执行单模板（需另行授权）

本模板不授予构建制品上传、切换、停服、重启或回滚执行权限。

## 放行前置

- 业主授权记录、责任人和明确切换窗口：待填。
- 源仓库、分支、完整 commit/tree、干净工作树及已审门检报告：待填。
- 实取 `go version` 全文，与上次现网件构建记录一致，且工具链为 go1.22.2；记录两侧全文及证据坐标。缺失、不一致或版本不符则停止放行。
- 仅从上述干净锚经 `SOURCE_COMMIT=<完整commit> ./build.sh <仓外输出目录>` 构建；脚本拒绝非 go1.22.2，不跳过其测试门。
- 制品 SHA、二进制自报版本/commit、备份和精确回退锚及命令：待填。
- 执行前回「已读本封＋实取UTC」；撤回时先停止并回「已停」。

## 切换与验收记录

授权内动作、实际 UTC、执行结果、五分钟门读数及业主验收结论逐项填入正式执行单。异常时按该单获批边界处理。旧件保留至组长另令清理。
