# 设计

## 决策

新增 `timelineTimestamp(node)` 和 `placeTimelineNode(node, fallbackBefore)`。定位函数优先使用节点显式 `data-timeline-ts`，否则读取卡片元数据中的 `.event-time[data-ts]`，按发送时刻升序插入；缺少时刻时沿用调用方回退锚点或追加。新建 turn-group 在内容尚未渲染前即保存事件时刻，避免空容器被误判为无时间节点。

用户卡、回合容器、Agent 卡与提及回复都通过定位函数插入。历史分页逐事件重放后，对本页新建节点再次调用同一函数；此操作是幂等的，并以同一时刻节点保持稳定顺序。保留分页前的可视锚点和滚动位置补偿。

## 边界

该变更不调整事件时间戳、回合归属、接收确认、等待区生命周期或 helper/Hub 协议。没有发送时刻的节点采用稳定的回退位置，不尝试推测跨事件顺序。
