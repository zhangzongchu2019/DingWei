## 技术冻结：A-AMEND-02

本文件先于产品提交冻结。无 AG 席的名字采用 `短名_EX` 后接创建时 128 位随机稳定 Agent ID 的 32 位小写十六进制部分。后缀仅标识外部席身份，不是组号、权限或租户。已存在 `短名_AG序号.属主简称` 地址逐字不变；两种地址均必须经 np_agent 与 np_extseat 权威解析，不能凭后缀放行。创建后加入、退出组或令牌更新均不改名，不分配虚假 AG0。随机冲突由现有唯一约束拒绝并回滚。

无配对是 OAuth 服务端 state 中绑定的显式选择；不得以回调 query 中空 target 绕过配对。新入口开启需要 feature flag。重新认证须绑定同一验证主体与明确席位；有歧义则拒绝，不以显示名合并身份或任选最新席位。

## 路由选择与授权

新 MCP 通信请求可显式携带 routing：mode=direct，或 mode=group、kind=ordinary/temporary、ref=稳定组码。缺少 routing 的旧请求仍表示该验证席原 AG，不能自动扩大权限；无 AG 旧请求返回 not_permitted。routing 是未信任的选择，绝不是授权快照。

权威查询在同一 PG 事务内检查双方 Agent、属主、外部席撤销及可信租户策略。ordinary 必须是真实 np_group，排除由 np_temp_group 对应的镜像；两端均为现成员。保留内部已有 leader_only 硬拒绝语义。direct 有多个有效路由时普通组优先，普通组按稳定 code 排序；没有普通组时才考虑真实有效 AG。显式 group 仅核该组，失效不借另一组。

首次受理后将 route_kind、route_ref、route_generation、source_agent_id、target_agent_id 持久绑定到消息。幂等比较包含客户端选择、目标与正文；相同 ID 重放不能重新选择另一组。PG 未投影发送、收件与 ACK 都重核已绑定路由，普通组不 TouchGroup。AG 仅按既有受理与首次 received 续期。普通组与配对的加入、退出互不转换、不重建、不续期。

身份鉴权与通信分离：无组或 AG 过期不妨碍身份验证和工具发现；所有通信工具须另过授权，无权限统一 403／1003／not_permitted，不返回正文、对端列表或收件租约。令牌到期仍停止所有认证，不删除成员关系。

## 成员管理、准入与回退

外部席入普通组仅由可信 Console 属主或平台管理员发起，不提供 MCP 自拉人入口。复用普通组关闭添加、组长保护和管理审计，外部席不获得管理员能力。feature flag 仅控制新增外部成员及新无 AG 开户；关闭后保留已存成员和身份，授权仍按真实现存组处理，不复活配对。

跨租户审批、tenant label 未冻结，保留策略接口但默认仍使用可信配置 TenantKey 精确匹配，绝不以客户端租户标签或入组代替准入。本片不实现跨租户开户。

## 迁移与跨库边界

仅新增 PG 0113，0112 留显示名切片。迁移器按文件排序并记 digest，不要求连续编号；已有稀疏编号不改。无 AG 关联用真实缺省值表达，不伪造临时组；旧消息补为 temporary 绑定，旧名字及 expiry 不改。内部目标保持现有 PG outbox→SQLite 幂等投影；外部目标只在同一 PG 事务写外部 inbox，不经过内部 helper 投影。不得在持有事务时再借一条 PG 连接。

PM01：已投影件仍按既有 SQLite 投递语义，不实现组失效后的撤回。普通组/AG 并存不改变该边界；未投影件只能重核原受理路由，不以仍有效的另一组挽救。N-6 失败通知另片，不能借本片扩大终态通知。

## 验证

同/异普通组的内部↔外部、外部↔外部、AG 并存/过期、显式组失效不换组、无 AG 未编组、令牌过期、重试路由绑定、外部自拉人拒绝、flag 回退、真实 PG 单连接及并发退出均有常驻断言。四把指定删保护须业务红。完整门按任务令运行，结果和 SKIP 条件逐条归档。
