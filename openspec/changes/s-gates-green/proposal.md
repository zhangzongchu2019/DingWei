# 三闸接入发布门

## Why

现网 r53 基线的仓储边界、依赖棘轮与租户负测前置三闸均已转红，却没有接入统一构建测试入口。本变更逐项登记新增调用与依赖，核实真实 schema 触发范围，并将三个检查变成发布前必跑且失败即停止的步骤，防止既有发布门继续漏过这些约束。

来源：组长 S-GATES-GREEN 2026-11-08T06:34:51Z；rulings 2275435d4a89a455ae8fc634ba021bf6989f9d43（㊾-补3问11、㊾-补5），复验 28611f8b。

## What Changes

- 逐处处理新增五处建库调用，保持原 open 基线5；依赖突破随 spec 登记。
- 租户闸按真实 schema 识别，真实落库列仍要求逐领域四项负测。
- 三闸接入统一发布测试入口，变异必须使其转红。
