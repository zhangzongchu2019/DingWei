# 设计

未知列表每次刷新先生成稳定的可见行模型，包含 delivery ID、显示文案、超时标记以及 helper 聚合计数。仅当模型签名变化时才更新摘要与列表 DOM；时钟 tick 可以刷新等待区的过期隐藏状态，但不得触碰未变化的列表节点。这样可保留按钮节点、焦点和悬停状态。

摘要 N 固定取当前页面可见明细行数。helper 聚合未知数大于明细数时，在列表外附加辅助说明“helper 上报 X 条；本页明细 N 条”；该说明不计作列表项。手动作废后本地可见行数立即减少，helper 原始聚合值继续原样说明来源。

移除 `deliveryByTurn`。该映射只有在 `cli_injected` 后才能建立，而该阶段会把 delivery 从等待区移除；delivery 已有的 assistant 输出事件通过同 delivery ID 直接标记处理，缺 delivery ID 的无关 assistant/reply 事件没有可靠关联证据，不应凭 turn ID 回推到已移除的未知条目。当前代码中没有一条能使映射变化重新提供或撤掉重发入口的可信路径。
