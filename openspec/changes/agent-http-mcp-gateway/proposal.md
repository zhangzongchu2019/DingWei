# 提案

## Why

外部 Agent 的目的只是与本团队平台 Agent 通讯，管理员预建席位会增加不必要的人工门槛。本变更把接入改为网页飞书扫码确认团队身份后自助建立临时双成员编组，签发受限且可吊销的 MCP 客户端令牌，使跨厂商协作可被寻址、审计和清理，同时保留编组隔离与现有 helper 通信边界。

## What Changes

- 飞书网页扫码且服务端核验本团队 tenant_key，通过后签发绑定稳定飞书身份的 OAuth 令牌；取消管理员预建席位。
- 归属显示名优先英文名，缺则中文转小写拼音字母；稳定身份使用带租户/应用命名空间的 open_id／union_id，不以显示名去重或授权。
- 每次接入指定目标、提交短名后自动创建 AG＋全局持久序号的临时编组，恰含外部 Agent 与目标 Agent；同一使用方可为不同目标分别建组。
- 外部 Agent 名为 `[a-z0-9]{1,8}` 短名＋下划线＋AG 名，例如 `mybot_AG3`；全局 AG 序号保证组合名唯一，不要求用户另做重名检查。
- 令牌每次成功鉴权交互滑动续期 14 天；编组消息发送或 ACK 滑动续期 3 天，自动/主动解散后通知两侧并处理在途消息。
- Console 在 Agents 列表下方单列与当前登录者相关的 AG；属性页展示成员、创建者归属名、创建/最后使用/到期时刻，提供受权、二次确认、带审计的解散。
- 一期按2026-07-28无状态Streamable HTTP MCP与同能力REST覆盖对话式和自主循环；二期私有WSS仅在必要时再做。MCP 与 REST 同能力、同权限，只有在线清单、普通消息、长轮询收件与 ACK；离线队列 24 小时、90 秒无成功请求即离线、长轮询上限 25 秒、MVP 仅显式全名提及、标准 OAuth 资源服务器与 Bearer 校验均已定。
