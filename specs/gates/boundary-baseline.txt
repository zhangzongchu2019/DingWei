#
# 🔴 不合并的理由：两条判据合成一个和，就允许「一个降一个升」而总数不变地过闸。
#    「合并未对撞」是已归纳的自造缺陷之一。

# include_tests —— 判据「仓储包外建库恒零」是否含 _test.go。
#   🔴 undecided = 业主尚未裁定（coordinator 2026-08-25T01:05:29Z 归口：业主回「改」但方向未明，正在回问）。
#   ⚠️ 未裁期间【两个计数都棘轮】—— 即两边都不许回升。
#      这样取的是保守侧：无论最终怎么裁，期间都不会有新口子被放进来，
#      也不会因为提前钉死一侧而让裁定变成「改回来」。
#   yes = 判据含测试文件，达标看 open_all；no = 只看生产码，达标看 open_prod，
#        且 open_all 转为参考值（回升不再拒，允许新增集成测试自建库）。
#   🔴 改这一行＝改判据，属评审面，非执笔方自决。
#
