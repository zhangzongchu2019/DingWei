# SP7a 仓储包边界基线 —— 每条判据【各记各的】，不合并成一个总数。
# 格式：<键> <自然数>；# 开头为注释。
#
# 🔴 为什么不合并成一个总数：两条判据合成一个和，就允许「一个降一个升」而总数不变地过闸。
#    「合并未对撞」是本席已归纳过的自造缺陷之一，此处按各判据独立棘轮。
#
# open   —— §22.2c #1 前半句：仓储包外直接建库句柄的处数（允许清单内豁免）
# escape —— §22.2c #1 后半句：裸库句柄逃出包外的处数（导出函数返回它 / 导出字段持有它）
#           🔴 这一条【允许清单不豁免】：仓储包自己导出一个 DB() 访问器，
#           正是「句柄出了仓储包」本身，豁免它等于把判据豁免掉。
open 6
escape 1
