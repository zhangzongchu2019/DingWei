# 平台 Spec 架构评审 checklist —— 安全门方

**签发者**：安全门方（reviewer-owned）  
**用途**：架构评审的输入；不是作者自检、不是实现验收，也不是门结果。  
**适用正文**：`docs/dingwei-platform-specdoc.md`；具体版本、锚与指纹以 `docs/DELIVERY-STATUS.md` 为准。  
**状态**：已签发，**未执行**。只有被指定的 reviewer 可将 `[ ]` 改为 `[x]` 或 `[!]`，并在证据栏填写可复算证据；作者与 implementer 不得修改勾选状态。

## 使用与判定

- 本清单由安全门方从附录 E.4 的候选输入中独立选择、合并并增补；并非把 E.4 原表机械复制为“已审”。
- 每项均须记录证据位置、执行命令或失败最小复现。任一 `[!]`、无证据的 `[x]`、或范围不清，均为本域 **NO**；存疑 fail-closed。
- 本文件只覆盖安全门方的架构评审责任域。其余 E.4 项须由相应门方形成同一轮的 reviewer-owned 输入；本文件不替其签署。
- 机器骨架（E.1 / lint / 测试）只作旁证，不替代本清单的人审结论。
