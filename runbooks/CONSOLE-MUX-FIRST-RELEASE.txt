1. Assembly and public API
cmd/workpulse/newplat.go assembles mux only for the real PG identity store. Memory mode retains legacy views. Console rendering is server-gated on actual assembly. Old independent view signatures are preserved.
GET /api/console/event-context: session-bound opaque auth_context, never cookie/hash.
POST /api/console/event-feeds: random console_instance, bounded desired subscriptions, request_id/auth_context; shared slot admission or visible 409.
GET /api/console/event-feeds/{feed_id}: own-session metadata.
PUT /api/console/event-feeds/{feed_id}: compare expected_revision; atomic replacement/refill. Ack-only updates validate per-seat applied against sent or already applied, without replacing subscriptions or increasing revision.
DELETE /api/console/event-feeds/{feed_id}: gate revoke, cancel writer/workers, wait writer completion, CAS release.
GET /api/console/event-feeds/{feed_id}/events: one browser SSE, no global event cursor.
All handlers use fresh primary session/user authority. Foreign session/principal feed IDs return generic 404. Writes verify Origin and session-bound auth_context. A token must not be included in a URL.
Control JSON <=16KiB, desired/applied/refill <=8, canonical full names and 32-hex instance/request IDs. Numeric revision is a metadata version; event seq/floor/H/applied/replay-round remain canonical decimal strings. Event cursors are epoch-seq.

2. B1 / D7 authority
identity.PGStore.AuthorizeConsoleMux uses fresh primary authority and DB-time expiry, then a single owned-active-Agent batch. Suspended/revoked Agents are not regranted. Must-change/disabled/revoked/expired sessions fail closed.
Existing Agent/user hooks retain their original projection/WS responsibilities and also revoke the mux registry. New OnSessionRevoked is synchronous. Logout revokes only the cookie's current hash before clearing the cookie; error never pretends success. Other login sessions remain valid.
Refresh every 400ms; whole primary round <=1s including DB admission wait. Positive lease expires check START+1s. No result-time extension. Concurrent revoke/retag invalidates the pending check version. Independent writer gate remains active even during a blocked query.
Shared principal+canonical-origin slot in 0300 migration: TTL3s, renew every400ms with400ms timeout, nonce+generation+session+instance CAS. DB clock governs ownership; local expiry conservatively subtracts request latency. No expiry resurrection. UpdateSlot never renews auth. Release occurs BEFORE exposing an inactive registry for reconnection. Old close cannot CAS-release a successor.
Write+Flush deadline250ms, additionally bounded by slot/session expiry and auth START+2s. Gate serializes the final check and socket write against revoke. Source readers terminate on gate/slot/session expiry and unregister removed bridge IDs. Already flushed bytes cannot be recalled. The <=2s property is a bounded window, not zero-delay revocation.
Eight feeds maximum per Hub, including retained metadata. DB budget <=16 executing and 64 admitted total (therefore <=48 waiting when all16 run, stricter than64 waiting). Context cancellation covers actual SQL, not just a waiting goroutine.
Feed-local recovery retention60s: timer-enforced and checked on access. Only desired identity, revision/vector and16-entry bounded idempotency metadata remain; gate, slot owner, payload queues and bridge state are discarded. Every reopen reacquires fresh authority and shared slot. No SharedWorker/union/multiple ports in first release.
A fresh opaque context probe once/second on an active top-level detects login changes across top-level pages. Identity changes close old transport, clear old frames and reload Console. Event transport retains no private BroadcastChannel channel or polling fallback. Empty desired union closes/relinquishes its transport.
Deployment must verify all Hub instances use the same primary slot authority and that a feed's short API requests reach its owning registry. PG prevents duplicate transports across authorities; it does NOT make an in-memory registry globally addressable. Missing affinity fails visibly rather than inventing shared state.

3. B2/B3 snapshot, replay and budgets
Same h.mu snapshot takes epoch/floor/H/empty/copied ring and registers bounded live reader. Empty ring floor=0, empty=true. epoch-0 is legal; after>same-lock H is409 cursor_ahead. Legacy wrapper signature/behavior preserved. New cleanup compares terminal AND reader instance.
Source emits begin, <=H replay, end, then >H live. The public queue separately gates each seat's begin/end phases: another seat's begin cannot be bypassed by a fair data pass. Refill round/iframe instance/generation fence stale frames. Managed rollover stops at seq_exhausted; shared legacy publisher is not changed.
Whole UTF8 SSE frame <=1MiB, control <=4KiB. Raw live256 events/2MiB per seat; aggregate encoded pending+sent2048/16MiB and seat256/2MiB; control64/256KiB. Sent-but-not-applied shares aggregate charge. Over-limit seat is stopped with visible gap; other seats remain active. No truncation/false applied.
Fair public/source passes max16 events or64KiB per Agent; one large whole frame then yields. Root sent credit16 is stricter than renderer64 and prevents EventSource flooding a paused renderer. Replay-end waits all pending <=H writes and data>H waits end.

Source writer uses native WriteString under the same writer gate, without copying a raw payload into another full source frame. Native HTTP writer/deadline capability is required and fail-closed if absent.

4. B4 VS / projection
Hub resolves trusted ViewTarget from the owned Agent identity; clients cannot supply target URL/key paths. One signed service aggregate bridge per target. Internal source endpoint verifies reverse direction, target, path/body, time and replay nonce, then binds registered bridge+feed+authorized scopes; one active source per bridge.
VS forwards complete bounded frames and continues per-seat cost effects before public output. Socket write250ms and abandoned-peer monitor close upstream readers promptly. Hub bridge retries at most3 total source attempts with100/200ms delay, fresh signed request and latest validated applied vector; exhaustion visibly isolates that target's seats. Dynamic groups cancel and fence old bridge IDs.
CostProjection is an inline VS SQLite transaction shared by aggregate AND signed independent-view sources: stable AgentID+epoch+seq unique completed key, insert and cost_total/cost_last/turns in ONE commit. Duplicate completion never clears cost_last or increments turns. Failure rolls back key and effects. Restart retains dedup. Same display name/new AgentID cannot inherit previous identity's state. Status uses the verified stable subject; old non-V2 legacy behavior is outside mux interop and not silently rewritten.
Cost DB is STATE_FILE+'.mux-cost.db', mode0600, outside release assets when STATE_FILE is outside them. Runtime DB/state/keys/login profiles are not release/evidence files. Existing three-file VS packaging still contains the complete inline implementation. Cross-target move/authority topology must be reviewed and measured; static routing ensures each identity's independent+managed consumers share its target projection.

5. Managed browser / S11
Console registers each actual iframe Window+random instance. Same origin/source/protocol/instance plus server AgentID/generation/replay-round must match. Child in managed mode never opens native /events. Independent view retains legacy code.
Managed seq parsing is BigInt/canonical decimal, never Number. Parent tracks only successful contiguous applied. Ready/await-ACK charged64/2MiB each seat and512/16MiB instance; dedup/gap handling never skips a missing event. Gap refills max3/5min with2s wait; visible history-incomplete/resync instead of hidden DOM clearing.
One event in flight per seat. Child completes dispatch, synchronous render flush and owned deferred merge rendering before applied=true. Duplicate retry of an in-flight application awaits its existing promise rather than mutating DOM again. Partial/unsafe failure sends negative nonretryable ACK, preserves draft/DOM, stops only that seat. Parent timeout2s per delivery; total2 deliveries initial+one retry, never indefinite retry. Decorative external attachment fetches are not represented as completed network fetches by event ACK.
Replays/reconnects preserve iframe document, draft and reading position. epoch_changed/history loss is visible. Registry loss can create a fresh feed using real per-seat applied and rebind generation without claiming missing history. Old EventSource callbacks cannot close a replacement transport.
